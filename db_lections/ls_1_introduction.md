"""================= база данных ================="""
- это хранилище где хранится определеная информация 
СУБД - система управления БД (mysql, postgresql, mongodb, oracle)
sql (structured query language) - язык для работы с БД
с помощью sql можем:
    1 создать БД, таблицу, добавить данные
    2 обновить таблицу, данные 
    3 просмотреть БД, таблицы, данные
    4 удалить БД, таблицу, данные 


"""================= типы данных ================="""
числовые - INT, BIGING, DECIMAL, FLOAT (age - INT, salary - DECIMAL)
------------------------------------------------
строчные - CHAR(255 символов ограничение), VARCHAR(255 символов ограничение), TEXT(бесконечное кол-во символов)
    CHAR(50 символов) = 'hello world'
    -если все символы не использовать заполнит пробелами
    VARCHAR = 'hello world'
    -если не использовать все символы он лишнее вырезает 
    
    name - VARCHAR(50)
    description - TEXT
------------------------------------------------
булевые(логический тип) - BOOLEAN - true/false 
is_admin = true/false
------------------------------------------------
дата и время - DATE(только дата), TIME(только время), DATETIME(дата и время)
birthday - DATE
created_at - DATETIME


"""================= SQL операторы и классы команд ================="""
все команды писать капсом

DDL - DATA definition language
команды для создания и изменения структуры базы данных:
CREATE -> создать
ALTER -> изменить
DROP -> удалить
RENAME -> переименовать
TRUNCATE -> очистка таблицы


------------------------------------------------
DML - DATA manipulation language
команды для работы с данными:
INSERT -> добавить данные
UPDATE -> обновить(изменить) данные
DELETE -> удалить данные


------------------------------------------------
DQL - DATA QUERY LANGUAGE
команды для получения данных:
SELECT -> выборка данных 



------------------------------------------------
DCL - DATA CONTROL LANGUAGE
команды для управления правами/доступами:
GRANT -> выдать права
REVOKE -> забираем права


------------------------------------------------
TCL - transaction control laguage
команды для управления транзакциями:
COMMIT -> сохранение изменений
ROLLBACK -> отмена изменений(откат)
SAVEPOINT -> точка сохранения

открыть
    mysql -u root -p

    \q

    SHOW DATABASES;
создать базу данных
    CREATE DATABASE <name of db>;
подключение к БД
    USE <name of db>;
удаление бд
    DROP <name of db>;

    CREATE TABLE <name of table>(

    -> email VARCHAR(100),
    -> birth_day date
    -> );
добавление данных(записей) в таблицу
    INSERT INTO <name of db>
    VALUES(1, 'aza', 22, 'aza@gmail.com', '2002-11-11');
получение данных(записей) с таблицы
    SELECT * FROM <name of table>;
